# 0033 · Nome das cores: mint, sky… ou green, blue…

**Data:** 9 nov 2026 · **Status:** Em aberto

**Contexto.** As rampas têm nomes com personalidade (mint, sky, tangerine). Nomes genéricos são mais fáceis para quem chega.

**Opções.** Manter os nomes atuais ou trocar para green, blue, orange. A troca é só nos primitivos, porque os componentes usam nomes semânticos (0001).
