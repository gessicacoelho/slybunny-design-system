# 0033 · As rampas de cor mantêm os nomes mint, sky e os outros

**Data:** 9 nov 2026 (aberta) · 12 nov 2026 (aceita) · **Status:** Aceita

**Contexto.** As rampas de cor têm nomes com personalidade (mint, sky, tangerine). Nomes genéricos (green, blue, orange) seriam mais fáceis para quem chega ao sistema.

**Decisão.** Manter os nomes atuais.

**Alternativas.**
- Trocar para green, blue, orange: mais óbvio para quem chega, mas exige renomear variáveis no Figma, chaves no JSON e variáveis no CSS, para quase nenhum ganho.

**Consequências.**
- Nada muda no Figma, no código ou no app.
- Quem usa o sistema trabalha com os nomes semânticos (`brand/primary`, `feedback/success`), não com as rampas (0001). Os nomes das rampas quase não aparecem no dia a dia.
