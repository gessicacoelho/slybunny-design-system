# Registro de decisões

Cada decisão tem um número fixo, data, status e quatro partes: **Contexto** (o problema), **Decisão** (o que fizemos), **Alternativas** (o que descartamos e por quê) e **Consequências** (o que muda, inclusive o que fica mais difícil).

Status possíveis: **Aceita**, **Em aberto**, **Substituída por N**.

Regra do registro: decisão nova ganha número novo. Se uma decisão mudar, a antiga não é apagada; ela vira "Substituída por" e a nova explica por quê.

## Como registrar uma decisão nova

1. Copie `_modelo.md` com o próximo número livre.
2. Preencha contexto, decisão, alternativas e consequências.
3. Acrescente a linha na tabela acima.
4. Abra um pull request: a decisão só vale depois de aprovada.
