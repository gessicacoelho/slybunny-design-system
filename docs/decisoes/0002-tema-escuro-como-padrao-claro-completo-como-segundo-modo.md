# 0002 · Tema escuro como padrão, claro completo como segundo modo

**Data:** 9 nov 2026 · **Status:** Aceita

**Contexto.** O app é escuro. O tema claro que existia no código não era usado e misturava cinzas antigos.

**Decisão.** Modo **Dark** é o padrão da coleção Color. O modo **Light** foi feito completo, não só "preparado", com todos os tokens conferidos em contraste.

**Alternativas.** Só escuro: menos trabalho agora, mas qualquer tema claro futuro exigiria refazer os componentes.

**Consequências.** Todo componente é conferido nos dois modos antes de sair de "Em revisão". Dobra o trabalho de revisão de contraste.
