# 0026 · Dialog só para o irreversível; Toast com "Desfazer" para o resto

**Data:** 10 e 11 nov 2026 · **Status:** Aceita

**Contexto.** Confirmações para tudo viram hábito: a pessoa toca "Sim" sem ler.

**Decisão.** O que dá para desfazer acontece na hora, com "Desfazer" num Toast. Dialog só para o que não tem volta (perder a ofensiva, sair da conta), com o verbo no botão e nunca "Sim".

**Alternativas.** Dialog para toda exclusão: mais seguro na aparência, menos seguro na prática.

**Consequências.** A confirmação volta a proteger quando importa.
