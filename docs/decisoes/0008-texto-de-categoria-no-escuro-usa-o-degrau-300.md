# 0008 · Texto de categoria no escuro usa o degrau 300

**Data:** 9 nov 2026 · **Status:** Aceita

**Contexto.** O documento original pedia o degrau 200 para o texto de categoria no tema escuro. O 300 já era usado na borda.

**Decisão.** `category/*/fg` usa o degrau 300 no Dark, o mesmo da borda, com contraste acima de 4.5:1.

**Alternativas.** Um token só para texto no 200: mais um token sem ganho visível.

**Consequências.** Um token a menos por categoria. Desvio do documento original, registrado aqui.
