# 0020 · Badge não carrega status e não mostra zero

**Data:** 9 nov 2026 · **Status:** Aceita

**Contexto.** Badges e tags se confundiam no app.

**Decisão.** Badge é só contagem ou ponto de novidade e some quando é zero. Status ("Atual", "Atrasada") é Tag.

**Alternativas.** Badge com texto: duas peças fazendo a mesma coisa.

**Consequências.** Cada peça tem um trabalho.
