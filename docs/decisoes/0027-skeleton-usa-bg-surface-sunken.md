# 0027 · Skeleton usa bg/surface-sunken

**Data:** 11 nov 2026 · **Status:** Aceita

**Contexto.** Com `bg/surface-raised`, o skeleton ficava invisível no tema claro, branco sobre branco.

**Decisão.** Blocos em `bg/surface-sunken`, visíveis nos dois temas.

**Alternativas.** Um token só para skeleton: um token novo para um caso que um existente resolve.

**Consequências.** Exemplo de por que todo componente é conferido nos dois modos.
